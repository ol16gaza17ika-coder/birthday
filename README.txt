ДЕНЬ РОЖДЕНИЯ — САЙТ С ПОЖЕЛАНИЯМИ

Структура:
  server.js      — сервер (принимает и хранит пожелания)
  package.json   — для хостингов с Node.js
  public/        — сам сайт: index.html, style.css, script.js, images/
  data/          — создастся сам, тут лежит wishes.json со всеми пожеланиями

Запуск на компьютере:
  1. Установи Node.js (nodejs.org), версия 16 или новее.
  2. В папке проекта выполни:  node server.js
  3. Открой в браузере http://localhost:8080
  (окно терминала нужно держать открытым)

На хостинге: загрузи всю папку, команда запуска — npm start (или node server.js).
Порт сервер берёт из переменной PORT автоматически.
ВАЖНО: wishes.json должен лежать на постоянном диске, иначе при перезапуске
некоторых бесплатных хостингов пожелания пропадут. Путь можно изменить
переменной окружения DATA_DIR.

Редактирование: тексты и фото — public/script.js (блок const CFG).
Примеры друзей (Аня, Маша, Катя, Оля) замени или удали: fr:[] — тогда
останутся только настоящие пожелания.
Удалить ненужное пожелание: открой data/wishes.json и удали его блок { ... }.

Если открыть public/index.html двойным кликом (без сервера), форма работает,
но пожелания сохраняются только в этом браузере.
